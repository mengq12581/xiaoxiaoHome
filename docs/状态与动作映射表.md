# 状态与动作映射表

本文件是导演层的行为字典。改行为只改这张表对应的配置（`config/activities.json`），不改导演代码。

## 一、字段约定

| 字段 | 含义 | 例子 |
| --- | --- | --- |
| `activity` | 活动 ID | `write_notes` |
| `anchor` | 交互点类型，落在家具的子节点上 | `desk_seat` |
| `anim` | 播放的动作 | `sit_write` |
| `min_dwell` | 最短停留秒数，没到不切 | `90` |
| `weight` | 空闲池权重，填 0 表示不进空闲池 | `20` |
| `duration` | 空闲时的随机持续区间（秒） | `[60, 240]` |
| `face` | 到位后的朝向（家具前向 / 固定方位） | `anchor_forward` |

## 二、活动表

| 活动 | 去哪（交互点） | 动作 | 最短停留 | 权重 | 来源 |
| --- | --- | --- | --- | --- | --- |
| `use_computer` | `desk_seat`（电脑桌前椅子） | 坐下、双手放键盘、屏幕微光、偶尔抬眼看屏幕 | 60s | 0 | 定时任务「上网」/ 模拟器 |
| `write_notes` | `desk_seat` | 坐下、翻开桌上本子、低头写、停笔想一想 | 90s | 0 | 定时任务「神游」10:10 / 15:10 / 模拟器 |
| `watch_tv` | `sofa_seat`（沙发坐点） | 坐下、面向电视、偶尔换坐姿、手放膝上 | 45s | 30 | 空闲池 / 模拟器 |
| `listen_music` | `sofa_seat` 或 `window_stand` | 戴耳机、靠坐或站着、头轻轻晃 | 45s | 20 | 空闲池 / 模拟器 |
| `sleep` | `bed_lie`（床） | 躺下、盖被、呼吸起伏、偶尔翻身 | 120s | 15 | 空闲池 / 模拟器 |
| `daydream_window` | `window_stand`（客厅窗边） | 站立、望向窗外、偶尔抬手贴玻璃 | 60s | 20 | 空闲池 / 模拟器 |
| `wander` | 全屋导航点随机 1～3 个 | 走动、偶尔停下看看 | 20s | 15 | 空闲池 |
| `eat` | `tea_table_seat`（茶几旁，v0.1 可留空实现） | 坐下、端碗 | 60s | 0 | 定时任务「午饭 / 晚饭」 |
| `idle_stand` | 当前所在点 | 站立呼吸、轻微摆动 | 10s | 0 | 兜底 |

`weight` 全为 0 时不会自动触发，只能由外部状态写入触发。

## 三、优先级

1. `task:*` 与 `sim:click` > `idle`。
2. 同优先级后写覆盖先写，但当前动作的 `min_dwell` 未走完时排队等待。
3. `sleep` 在中途被任务打断时，先坐起来再下床，不允许直接穿模站到地上。
4. 睡眠时段（配置里 `quiet_hours`，默认 23:30–07:30）空闲池权重切换为「睡觉 60%、窗边发呆 25%、闲逛 15%」，但任务状态仍可打断。

## 四、外部任务 → 活动 映射（Hermes 侧定时任务）

| 任务 | 时间 | 写什么状态 | 说明 |
| --- | --- | --- | --- |
| 神游 | 10:10 | `write_notes`，`source: task:daydream`，`min_dwell: 90` | 她在电脑桌上打开本子写笔记 |
| 神游 | 15:10 | 同上 | 下午那场 |
| 上网冲浪 | 不定期（每周两次） | `use_computer`，`source: task:browsing`，`min_dwell: 60` | 坐在电脑桌旁玩电脑 |
| 午饭 | 12:15 | `eat`，`source: task:lunch`，`min_dwell: 60` | v0.1 可只记日志不演出 |
| 晚饭 | 18:30 | `eat`，`source: task:dinner`，`min_dwell: 60` | 同上 |
| 归档 / 交接 | 23:40 / 23:50 | 不写状态 | 后台活儿，不出现在屋里 |
| 健康晚报 | 23:30 | 不写状态 | 同上 |

任务结束不需要「写结束」，导演靠 `min_dwell` 与超时回落到空闲池；若任务想显式收尾，可写 `{"activity":"idle"}`。

## 五、动作过渡规则

- 站 → 坐：先走近交互点 0.6m 处，转身朝向交互点，再下坐（约 1.2 秒）。
- 坐 → 站：先起身，再转身，再走（约 1.0 秒）。
- 走 → 走：路径重算时最多 0.4 秒的原地过渡，不许原地抽搐。
- 躺 → 坐 → 站：分两段，共约 2.5 秒。
- 任何过渡期间不接受新的走位指令，但接受状态排队。
- 任务实际持续 3 秒，也要把 `min_dwell` 走完再收尾——这就是「看到的笑笑会晚一会才结束」。

## 六、交互点挂在哪儿

| 交互点 | 所属家具 | 说明 |
| --- | --- | --- |
| `sofa_seat` | 沙发 | 三个座位取中间；沙发一转，坐点跟着转 |
| `desk_seat` | 电脑桌 | 椅子跟着走；桌子和椅子是联动家具组 |
| `bed_lie` | 床 | 床中偏头一侧 |
| `window_stand` | 窗 | 窗前 0.8m 站位，朝窗 |
| `tv_face` | 电视柜 | 只作为朝向参考，不站人 |
| `tea_table_seat` | 茶几 | 预留 |

家具被拖动时，交互点作为子节点自动跟随；地面导航图是固定的，路径按最新交互点重算。正在使用家具时拖动，导演先记一次性动作「做完手上的再起身」，然后走新位置。
