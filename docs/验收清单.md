# 验收清单

用法：每个里程碑结束按对应分组逐条打勾；不能跳着验。打不了勾的写进 `docs/验收问题.md`（现象、复现步骤、期望），修完再验。

标记：`[ ]` 未验 / `[x]` 通过 / `[!]` 不通过 / `[-]` 不适用

## 0. 启动与工程

- [ ] 全新目录克隆/解压后，`npm install && npm run dev` 一条命令起得来，浏览器自动打开能看到屋子。
- [ ] 断网状态下重启一次，仍能完整运行（不请求任何外部地址，可开 DevTools Network 核对）。
- [ ] `npm run check` 全绿，无 skipped 用例。
- [ ] 仓库里没有提交 `runtime/`、`node_modules/`、`logs/`。
- [ ] README 写清：怎么跑、怎么验收、选了哪些技术方案及理由、已知限制。

- [x] 任意角度都能看见角色：挡视线的墙自动透明或只留轮廓，转回来恢复实体。（M1：四个方向 `m1-01`～`m1-04`；M2：遮挡检测加入角色头部与身体，隔着内墙看床边 `m2-c-at-bedside.png`）
- [x] 相机始终在屋外，进不去室内；不会出现墙体整片消失或里外双面遮挡。（M1：贴近屋体自动拉开；远侧墙始终实体）

## 4. M4 空闲池

- [x] 静置 5 分钟内至少换过一次活动，顺序不固定。（M4：启动 3 秒后空闲池接手，每件 60～240 秒；单测模拟 5 个随机种子；浏览器快进实测）
- [x] 静置 20 分钟，日志里出现 ≥ 3 种活动，且有权重差异（不是平均分布）。（M4：`npm run state -- --stats 20` 统计；单测模拟一周：看电视次数约为睡觉 / 闲逛的 1.6 倍。冷却会把分布拉平一些，见 `docs/验收问题.md` B23）
- [x] 23:30 之后（或临时把 `quiet_hours` 改成当前时间段），空闲池切到睡眠为主。（M4：单测模拟一整夜；浏览器在 UTC 凌晨实测只出现睡觉 / 窗边 / 闲逛）
- [x] 空闲时写入任务状态，能在最短停留后打断空闲行为。（M4：单测）

## 5. M5 家具拖动

- [ ] 双击沙发高亮，拖动到另一角，松手后她下一次看电视走到新位置，准确坐下。
- [ ] 拖动电脑桌时她正在用电脑：她做完手上的动作再起身走向新位置，不留在空气里。
- [ ] 电脑桌与椅子联动移动（`group` 生效）。
- [ ] `Ctrl+Z` 撤销一步；刷新页面后布局保持；「恢复默认」能回到配置初始位置。
- [ ] 拖动时角色不会穿进被拖动的家具（或在拖动暂停路径并重算）。

## 6. M6 状态模拟器

- [ ] 双击 exe（或打包产物）启动，无需浏览器即可操作。
- [ ] 点「写笔记」3 秒内浏览器角色响应；点「停下」她回到空闲并进入空闲池。
- [ ] 模拟器窗口显示当前状态、来源、开始时间、最近 20 条历史。
- [ ] 浏览器关掉再开，模拟器仍可用，状态继续生效。
- [ ] 端口被占用时自动顺延并给出可读提示，模拟器能手填端口。
