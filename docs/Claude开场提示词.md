工作目录：<改成你机器上的绝对路径，例：D:\projects\xiaoxiao-home>

5. docs/验收清单.md        —— 验收怎么打勾

先做 M1：仓库骨架 + Vite + TypeScript + three.js（或你选的方案）+ 按 config/ 生成一室一厅 + 斜俯视相机 + 90° 步进旋转与缩放。做完给我看。

## 我（客户）这边怎么接

1. 他跑完 M1 会来汇报，你把结果转给我；我按 `docs/验收清单.md` 第 1 组逐条核，核过再放他进 M2。
2. 每个里程碑我都想看一次浏览器里的实际效果，不接受「代码写好了」。
3. 他不许碰服务器；以后接我的服务器与网络，由我另行安排，这一版文档里没有这项任务。
