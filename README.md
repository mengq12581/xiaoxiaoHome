# 小家 3D

本地离线运行的 3D 一室一厅，Q 版笑笑住在里面。需求见 [docs/PRD.md](docs/PRD.md)，验收见 [docs/验收清单.md](docs/验收清单.md)，执行中的约定与变更见 [docs/验收问题.md](docs/验收问题.md)。

## 怎么跑

只需要 Node.js LTS（20 及以上）。

```bash
npm install
npm run dev
```

开发服务器只监听 `127.0.0.1:5173`，启动后自动打开浏览器（Chrome / Edge）。不想自动打开时用 `npm run dev -- --no-open`。

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 开发版，改 `config/*.json` 保存后自动重新加载 |
| `npm run check` | 类型检查 + 单元测试（配置合法性、墙体与门窗洞几何、家具坐标） |
| `npm run build` | 打包到 `dist/`（离线可用） |

## 操作

- **左键拖动**：绕屋子自由环绕（水平 360°，俯仰角 25°～70°，不会钻到地板下）
- **滚轮**：连续缩放（4.5～16 米）
- **复位视角**：左上角按钮
- 挡住视线的墙（包括挡住笑笑的墙）自动变半透明、只留轮廓线；转到别的角度后恢复实体
- 拉近时镜头会慢慢移向笑笑，拉远后回到户型中心
- 开发态右上角有「M2 走位演示」面板：走到床边、坐电脑椅、坐沙发、去窗边、站起来、无解测试、镜头看她（地上的虚线是当前路径）。M3 起改由状态驱动，打包产物不含这个面板

## 怎么验收（M1）

1. `npm run dev`，5 秒内看到整屋：客厅、卧室、门洞都在画面里。
2. 左键左右拖一整圈、上下拖到底；滚轮推到最近、拉到最远。
3. 转到各个方向，看挡视线的墙是否透明、背面的墙是否恢复实体。
4. 改 `config/furniture.json` 里沙发的 `position`（如 `[0.55, 3.3]`），保存后页面自动重载，沙发换位置。
5. 在 `config/rooms.json` 的 `rooms` 里加一个房间，例如
   `{ "id": "study", "name": "书房", "bounds": [[9.5, 0], [12, 3]], "floor": "carpet", "walls": [], "doors": [] }`，
   场景多出一个房间，与卧室相邻的墙自动变成内墙。
6. 故意写错配置（如家具 `kind` 写成 `spaceship`）：`npm run dev` 直接报错退出，指出文件与字段；开发中改错则浏览器出错误遮罩。
7. `npm run check` 全绿。

## 怎么验收（M2）

1. 对照 `docs/screenshots/char-01-turnaround.png`（程序渲染的正 / 斜侧 / 侧 / 背）与 `assets/xiaoxiao_q_turnaround.jpg`；走路、坐姿、眨眼见 `char-02`～`char-04`。
2. 点「走到卧室床边」：她沿虚线从客厅穿过门洞走到床边，转角处先转身再走，不穿墙、不穿家具。
3. 点「坐电脑椅」：走到椅子后方站位 → 停住 → 转身面向桌子 → 用 1.2 秒坐下；再点「坐沙发」：先起身（1 秒）再走过去坐下。
4. 坐下过程中点别的按钮：她先坐好再起身执行（指令排队，不打断过渡）。
5. 点「无解测试」（目标在衣柜里）：原地不动，控制台出现 `寻路失败，原地停下` 警告。
6. 点「镜头看她」或滚轮拉到最近：能看清眼睛、腮红、音符发卡。
7. 把 `config/characters.json` 的 `active` 改成 `shuaishuai`：换成帅帅（短发、圆框眼镜、太阳 T 恤、藏青短裤、白袜），走路、坐下、眨眼照常，不报错。对照图 `docs/screenshots/char-07`～`char-11`。

## 技术方案及理由

| 关注点 | 选择 | 理由 |
| --- | --- | --- |
| 渲染 | three.js 0.170（原生） | 生态最大、问题好查；不需要 React 那层 |
| 工程 | TypeScript + Vite 5 | 导演层是状态机，类型能省调试；Vite 起得快 |
| 相机 | three.js 自带 OrbitControls + 自写「不进屋」约束 | 自由环绕、连续缩放；极角与距离由 `config/camera.json` 控制 |
| 墙体遮挡 | 每段墙独立 mesh + 每帧射线检测 | 从相机向每个房间地面采样点（约 1 米一个）打射线，命中的墙段淡出到 `wallFadeOpacity`，保留轮廓线；不做「整屋 X 光」 |
| 墙与门窗 | 按房间 `bounds` 自动生成四面墙，公共墙合并为一段内墙，门窗按区间切块 | 真实开洞、有厚度；加房间只改配置 |
| 家具与贴图 | 基础几何体程序化建模，地板贴图用 canvas 生成 | 零外部素材，断网可跑 |
| 画面风格 | 柔和 3D 游戏观感（`src/scene/lookdev.ts`）：程序生成的柔光环境照明 + 哑光 PBR 材质 + 柔边阴影 + 环境光遮蔽（GTAO）+ 4× MSAA + 渐变背景 | 平涂材质加硬阴影看起来像色块拼的；环境光和遮蔽让曲面有连续明暗、物体「落」在空间里。帧率低于 24 时自动关掉遮蔽，`?fx=off` 可手动关闭后期 |
| 配置校验 | 自写校验器，Vite 启动时和浏览器加载时各跑一遍 | 错误直接指出「文件 + 字段路径」，不静默兜底 |
| 测试 | Vitest | 与 Vite 同栈 |
| 角色 | 笑笑和帅帅都用开源多视图建模工具 Hunyuan3D-2mv 从三视图生成网格，再由 `tools/character/` 的脚本烘焙贴图、计算蒙皮权重、生成眼睑，导出 `assets/models/<id>.glb`；运行时绑到同一副 11 关节骨架上。每个角色的尺寸和服装类型写在 `tools/character/chars/<id>.json` | 手搓几何体还原不了原画的头发和脸；建模工具给出的轮廓与三视图剪影重合约 86%～96%。动作代码不用改，游戏运行不依赖 Python、不联网。重做模型的步骤见 [tools/character/README.md](tools/character/README.md) |
| 待机与坐姿 | 呼吸起伏、2.5～6 秒随机眨眼、重心左右轻摆；坐姿上身前倾、膝盖并拢、两腿一前一后、手搭膝上 | 客户整改要求（docs/验收问题.md C4） |
| 接触阴影 | 脚下一团柔和暗影，坐下时座面上再加一团，与主光阴影叠加 | 不让角色看起来浮着 |
| 家具观感 | 全部大圆角软体块（木 / 漆面圆角到 4 厘米，布艺到 9 厘米）；哑光木纹、织物、暖白三类材质；无描线、无金属高光；门框倒圆、门洞上方内角做圆角 | 客户整改要求（C5） |
| 寻路 | `rooms.json` 导航点图 + 起终点可见性连线 + A* + 拉直；障碍 = 落地墙块 + 家具占地矩形（按角色半径 0.25 米膨胀） | 「加房间只加配置」；被挡住的导航边自动停用，家具挪动后重算即可（M5） |
| 走位 | 每帧朝下一个路点直线前进（0.75 m/s），转角超过 50° 先原地转身；步频跟着位移走，脚不打滑；坐下 1.2 秒、起身 1.0 秒缓动 | 不瞬移、不滑行；过渡中来的新指令排队 |

状态服务（Node 原生 http）、行为导演、Electron 模拟器在后续里程碑加入。

## 目录

```
config/        房间、家具、活动、角色、相机配置（改这里不用改代码）
src/config/    配置类型、加载与校验
src/scene/     户型几何（layout.ts，纯函数）、墙体与门窗、家具模型、交互点、相机、墙体遮挡
src/nav/       寻路（纯函数）
src/character/ 角色骨架、模型与贴图、走位与基础动作
src/ui/        屏幕叠加层、开发态演示面板
tests/         单元测试
docs/          需求、约定、验收；docs/screenshots/ 是里程碑截图
assets/        角色三视图；assets/models/ 是由三视图生成的角色模型（GLB + 关节信息）
tools/character/  三视图 → 角色模型的建模流水线（Python，仅重做模型时用）
```

坐标约定：平面坐标 `[x, y]`（米），x 向右、y 向上；家具 `position` 是全屋绝对坐标，`rotation` 逆时针为正，0° 时家具正面朝 +y。详见 `docs/验收问题.md` B1–B5、C3。

## 已知限制

- 墙体不投影（墙会动态透明，投影会在透明墙后留下黑影），屋外地台也不接影子。
- 相机目标点固定在 `config/camera.json` 的 `target`；加房间后若想居中，需手动改 `target`。
- 浏览器标签页在后台时渲染循环会暂停（浏览器行为），切回即恢复。
- 家具不参与透明：她走到电视柜、书架后面时会被家具挡住（文档要求家具不透明）。
- 寻路失败目前只写浏览器控制台；写入 `logs/` 文件要等 M3 的本地状态服务。
- 坐下只有「坐」一种姿势；躺下、伏案、看电视等动作在 M3 随活动一起做。
